AniKitty 0.7.8 - Watch player UX overhaul

ADDED
- Per-episode provider capability badges (S/D) — see which sources have sub or dub for the current episode.
- Remember your preferred provider per anime; smart ordering puts working sources first.
- Stuck-loading banner after 12s with a one-tap “try another source” action.
- Auto-fallback discovery hint on first stream failure — opt in to switch sources automatically.
- Episode jump input and mark-complete button on the episode bar.
- Stream info strip — provider, audio, server, quality, and API node at a glance.
- Quality and site-server picker for MegaPlay/Anikoto (alternate mirrors via linkId).
- Mobile swipe prev/next on the video, PiP toggle in the toolbar, and next-episode thumbnail in the end overlay.
- Live episode preview on hover in the episode bar.
- Theatre mode dims the page behind the player.

IMPROVED
- “Try another source” on stream errors; provider chip stays visible when controls are hidden.
- Held-stream shell keeps playback position when switching provider on the same episode.
- Provider picker grays out sources that are unavailable for the current episode and audio mode.

REMOVED
- Hard-sub row removed from the provider picker — only Soft sub and DUB rows remain.
