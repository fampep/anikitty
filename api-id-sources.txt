How Anikitty Gets External Database IDs
========================================

The whole system chains two APIs together:

STEP 1 — ani.zip (built on Fribb/anime-lists)
-----------------------------------------------
URL:  https://api.ani.zip/mappings?anilist_id={id}
Free: yes, no API key needed
Repo: https://github.com/Fribb/anime-lists

You pass an AniList ID and get back a mappings object
that contains IDs for every major anime database:

  anilist_id      — AniList         https://anilist.co/anime/{id}
  mal_id          — MyAnimeList     https://myanimelist.net/anime/{id}
  anidb_id        — AniDB           https://anidb.net/anime/{id}
  thetvdb_id      — TVDB            https://thetvdb.com/?id={id}&tab=series
  themoviedb_id   — TMDB            https://themoviedb.org/tv/{id}
  kitsu_id        — Kitsu           https://kitsu.app/anime/{id}
  animeplanet_id  — AnimePlanet     https://anime-planet.com/anime/{id}
  livechart_id    — LiveChart       https://livechart.me/anime/{id}
  imdb_id         — IMDb            https://imdb.com/title/{id}
  notifymoe_id    — Notify.moe      https://notify.moe/anime/{id}

The same response also includes a small images object
with a single banner, fanart, and poster from TVDB.


STEP 2 — TVDB API v4 (for the full Art tab)
---------------------------------------------
URL:  https://api4.thetvdb.com/v4
Docs: https://thetvdb.github.io/v4-api/
Free: yes, requires a free account + API key

Using the thetvdb_id from Step 1, we hit:
  GET /v4/series/{thetvdb_id}/artworks   (for TV series)
  GET /v4/movies/{thetvdb_id}/artworks   (for movies, fallback)

This returns ALL artwork in the TVDB database for that anime:
  type 1  / 24 — Banners
  type 2  / 23 — Posters
  type 3  / 22 — Backgrounds / Fanart
  type 14 / 25 — ClearArt (transparent PNG)
  type 15 / 26 — ClearLogo (transparent PNG)

Results are sorted by score so the best images come first.
Each artwork has a thumbnail URL (small) and full image URL.


WHERE THE ANILIST ID COMES FROM
---------------------------------
The AniList ID is fetched when the user opens an anime page.
The anime detail API (HiAnime → our backend) returns anilistId
as part of the moreInfo object. That ID seeds everything else.


SUMMARY OF FLOW
----------------
  User opens anime page
        ↓
  GET /api/anime/{anilistId}/mappings   (our Next.js route)
        ↓
  ani.zip  →  returns all cross-DB IDs + 3 basic TVDB images
        ↓
  TVDB API →  returns full artwork gallery (using thetvdb_id)
        ↓
  Page displays:
    - External Links section (Overview tab)  using all the IDs
    - Art tab                                using TVDB artworks
    - Banner image                           TVDB fanart → AniList → poster
