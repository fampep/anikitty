# AniKitty v2.0.0 Discord Changelog

## Big UI Refresh

AniKitty 2.0.0 is focused on making the site feel more original, polished, and less like copied layouts from other anime sites.

## What's New

- Redesigned the Genre page with a new spotlight layout, quick genre pills, custom genre cards, and cleaner results.
- Redesigned the Homepage with a more original content flow, new signal band, improved section layouts, and stronger visual identity.
- Updated the Homepage hero so the banner artwork fills the top area better instead of leaving empty dark space.
- Redesigned the Watch page with a custom cinema-style layout, stronger player frame, better title/action row, improved source panels, and cleaner episode/sidebar styling.
- Improved the top navigation bar with better hover animations, icon motion, active states, and a more custom floating style.
- Improved search popout styling so results feel clearer, more modern, and easier to scan while typing.
- Redesigned the profile dropdown menu with a custom profile header, XP card, Kittycoins tile, animated menu rows, and cleaner sign-out area.
- Improved profile menu/select controls so the profile page tools feel less default and more consistent with the new design.

## Profile Updates

- Profile activity now shows anime currently being watched.
- Activity includes episode progress and how many episodes are left.
- Profile pages now show when a user was last online.

## Polish

- Improved hover effects across navigation, dropdowns, search, and profile controls.
- Added more consistent panel styling across homepage, watch page, search, genre, and profile areas.
- Reduced copied/default-looking UI patterns and moved pages toward a more unique AniKitty design.

## Version

Released as `v2.0.0`.
