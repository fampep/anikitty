Add TVDB_API_KEY to Vercel Production Environment Variables
============================================================

1. Go to your Vercel project dashboard
2. Settings → Environment Variables
3. Click "Add New"

   Name:   TVDB_API_KEY
   Value:  2d138ad2-2ee3-45c6-bcce-49f7e52c9bfc

4. Check "Production" (and "Preview" if you want it there too)
5. Make sure "Available at Runtime" is ON
   (buildtime is NOT needed — it is read at request time only)
6. Click Save

7. Redeploy your app so the new variable takes effect:
   Deployments → pick latest → ... menu → Redeploy
