AniKitty v1.0.0 — Stable

AniKitty is now marked stable at version 1.0.0.

Providers
- Whiskey (AniWaves) is the default provider
- Echo (MKissa) second, Alpha (AniKuro) third
- New: Sierra (AniSnatch) — fast stream-direct, listed after Alpha
- Whiskey race now uses all healthy KittyAPI nodes so working peers are not skipped
- Cleared bad AniWaves caches (junk analytics URLs that blocked playback)

Playback
- Echo/MKissa progressive MP4 behind the kitty HLS proxy plays correctly
- Cast detects MP4 vs HLS more reliably
- Skip Intro raised for TV remotes
- Player stall-on-resume and control overlap fixes
- Mobile fullscreen / subtitle / Cast polish from recent builds

Site
- Version bump: 0.9.1 -> 1.0.0 (stable)
