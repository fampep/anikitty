AniKitty

An Android app for your AniList. The catalog, lists, and schedule come from AniList. The phone plays the video. A stream plays only when an extension resolves a URL. The default APK does not include a community extension.

 Write an extension

An extension is an HTTP resolver. It is not code loaded into the APK.

 Protocol

apiVersion 1. The phone sends an AniList id and an episode. The extension returns URLs.
