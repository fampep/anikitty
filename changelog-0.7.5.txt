AniKitty 0.7.5 - New home, custom subtitle fonts & more servers

ADDED
- Custom subtitle fonts: pick from a set of built-in styles or upload your own font file from your device to use everywhere subtitles show.
- Several new streaming servers added and the server list reworked, so more titles have a working source and failover has more options.
- Adult-content toggle in Settings: 18+ titles are hidden by default and can be shown when you opt in.
- Smarter search: filter by year and cycle genres to include or exclude them.
- Player extras: quick skip/rewind buttons, a touch-to-seek toggle, an auto-enable subtitles option, and a hard-sub overlay toggle.
- MP4 playback support for sources that don't stream over HLS.

IMPROVED
- Redesigned home page with a cleaner cinema-style layout, poster rail, and refined AniKitty glass theme.
- Faster, smoother watch and search pages, with less lag while a video is playing.
- Tidier settings: subtitle and player options are now organized into tabs.
- Search now has keyboard navigation, browse pages show a clear retry option when data fails to load, and the player announces loading states for screen readers.
- Streaming servers now use consistent, simplified labels across the player.

FIXED
- Pause button is reliable again: clicks no longer register without actually pausing.
- Quality and settings panels in the player scroll properly so every option is reachable on small screens.
- Subtitles show correctly across servers, including hard-sub sources, with fewer flickers and reloads.
- Fixed a player freeze loop and a crash on streams that didn't report a quality list.
- Search filtering by genre works correctly again.
