AniKitty 0.7.10 - Theatre mode, stream hardening, and community polish
Date: 2026-07-16

FIXED
- Theatre mode works again — no longer reset by account settings sync
- Theatre mode is local-only (not overwritten from server prefs)
- Dark overlay, exit bar, Esc to exit, T to toggle
- Mobile episode list hidden while theatre mode is on

ADDED
- Opaque session-bound HLS stream tokens (/api/kitty/hls?t=…)
- HttpOnly playback session cookie (tokens alone are not enough to scrape)
- Production disable-devtool guard (F12 / right-click / common shortcuts)
- Comment spoiler hide toggle and jump-to-latest
- Level card watch vs comment XP split and next-rank preview
- Role badge hover descriptions

IMPROVED
- Stream proxy: 45-minute token TTL, same-origin checks, rate limiting
- Plaintext ?url= HLS fallback removed; client no longer builds upstream URLs
- Level tier icons on comments and replies
- Restored HilltopAds click ads
- Tighter home explore bar spacing

NOTES
- disable-devtool is off in development and on /admin
- Optional bypass: set NEXT_PUBLIC_DISABLE_DEVTOOL_MD5 and open ?ddtk=<secret>
