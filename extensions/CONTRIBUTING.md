# Contributing to AniKitty Extensions

## Add a store listing

1. Ship a public GitHub repo with a valid root `anikitty-extension.json` (or document `manifestPath`).
2. Open a PR that appends an entry to [`store/index.json`](./store/index.json).
3. Keep descriptions short; mark `featured` only if maintainers agree.

## Spec changes

Protocol bumps require a new `apiVersion` and matching Android client support. Open an issue first.

## Code of conduct

Be kind. No malware, credential harvesting, or deceptive manifests. Listings that break trust get removed.
