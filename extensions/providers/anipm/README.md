# Ani.pm

On-device resolver compiled into the AniKitty app from this folder.

`AniPmServer.kt` maps an AniList id to ani.pm, then to a Settlar HLS master and captions. The app plays that master directly.

The extension version of Ani.pm is built here. The phone still plays the stream itself.
